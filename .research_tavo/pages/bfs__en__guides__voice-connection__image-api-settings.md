Image Generation API Settings

The image generation entry is under "More" > "Voice & Image Generation". Inside this section, you will find "Image Generation API" and "Image Generation Settings".

Setup Path

Open the left sidebar and tap "More".

Enter "Voice & Image Generation".

Tap "Image Generation API", then tap "Add New" in the upper-right corner.

Choose the image generation platform you want to use.

If you use Volink, tap "One-click API Setup" on the platform card and follow the guide to finish the account, API key, and connection setup.

If you already have a key, enter the API key, choose the required model or platform options, and tap "Save".

Enable Image Generation

After saving successfully, the image generation API can be used for later image requests.

"Image Generation API" is the entry for enabling image generation. Return here when you need to edit, remove, or switch configurations.

Voice APIs and image generation APIs are managed under the same "Voice & Image Generation" section, but their configurations are independent.

Troubleshooting

Save failed or connection failed: Check your network connection, proxy status, and whether the key belongs to the selected platform.

Saved successfully: The image generation API is connected. You can continue to Image Generation Settings to adjust how generated images are described in chat history.
