🎨 Themes

Set Chat Theme

You can customize the overall visual style and interface elements of the chat through the sidebar.

Operation Path

Open the left sidebar.

At the bottom, find and click the "More" option.

From the expanded menu, select "Themes" to enter the theme management interface.

Theme Function Description

In this interface, you can:

Select Theme: Directly apply the "Official Default Theme" or a "Custom Theme" you have already created.

Copy and Modify: Copy any official theme as a template for personalized secondary modifications.

Customize Elements: Adjustable visual elements in themes include:

◦ Chat background, status bar

◦ Messages: Message bubble style, font

◦ Characters: Chat avatar display method

◦ Functions: Internal monologue prompt style

Presets

**Presets** refer to a set of **basic configurations and behavior patterns** established for characters, helping you quickly set up identity, personality, behavioral guidelines, etc., for characters, reducing repetitive setup work. Through presets, you can quickly create characters or scenarios that meet specific needs. These presets will determine how characters behave, their dialogue style, and how they interact with users.
