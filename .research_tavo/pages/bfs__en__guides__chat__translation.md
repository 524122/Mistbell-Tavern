Message Translation

Message translation is configured under chat settings and can be used directly from a chat bubble.

Open Translation Settings

Operation Path

Open the chat settings page.

Tap Translation.

Enable Message Translation.

Translation Options

Target Language: choose the language that chat messages should be translated into. You can use the current device language or select another language.

Translation API: optionally assign a dedicated API for translation. After it is set, translation requests use this API instead of the chat API.

Translation Prompt: controls how messages are translated. Keep {{language}} and {{content}} in the prompt so Tavo can insert the target language and message text.

Translate a Chat Bubble

After message translation is enabled, long-press a chat bubble and tap Translate in the action menu.

Suggestions

Use a dedicated translation API if you want translation traffic to be separated from normal chat traffic.

Keep the prompt concise unless you need a specific translation style.

If the translation result is too literal, adjust the translation prompt to request natural, idiomatic output.

Chat Operations

You can use the character filter feature to quickly locate conversations with specific characters.
