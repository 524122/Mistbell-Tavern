Beginner Recommendation: One-click Setup

If this is your first time using Tavo, tap "One-click Setup" on the quick start screen.

Then follow the guided setup:

Tap "Start Setup". Tavo will register or connect Volink first.

Wait for Tavo to create the Volink anonymous account, grant credits, create the API key, and create the API connection.

Tap "Choose Model" and select an available model.

Tap "Import Demo Character" to import the sample character.

When everything is ready, tap "Start Chatting".

One-click setup is recommended for beginners who are not familiar with APIs. If you already have an API key, you can continue with the manual tutorials below.
