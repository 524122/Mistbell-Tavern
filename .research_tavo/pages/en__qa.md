FAQs

This page summarizes common issues encountered by users while using Tavo, along with corresponding solutions. If you encounter a problem, we recommend first consulting the guidance below. If the issue remains unresolved, please contact our official customer support for further assistance.

1. How to Enable and View Context Logs

After enabling this feature, you can view detailed technical dialogue logs in real-time within the chat interface, including token consumption and function triggering, facilitating performance analysis and troubleshooting.

Operation Path

Open the left sidebar.

Click the "More" option, locate and select "Settings" from the expanded menu.

After entering the settings interface, select the "Chat Settings" tab.

Scroll down on this page, find the "Context Log Switch," and set it to the "On" state.

Viewing Logs

After turning on the switch, return to any chat interface.

Click the sidebar icon in the top-right corner to open the right-side function panel.

Scroll to the bottom within the sidebar and click the "Logs" entry.

Upon entry, you can view detailed technical logs for the current conversation, mainly including:

◦ Token Consumption: Details of token usage for messages and replies.

◦ Function Invocation Status: Matching and triggering status of features such as World Book, regular expression rules, and presets.

◦ Other detailed records of context construction and model calls.

2. Why Does Only One "Re-Roll" History Remain After Restarting the App?

Reason: This is a normal system design behavior.

Specific Rules Are as Follows:

Session-Level Retention: The "Re-Roll" options and history are temporarily retained only during the current application session.

Globally Valid Within Session: During the current usage period, the history is retained regardless of switching chats or navigating through messages.

Session-End Cleanup: After closing the app and restarting it, the system automatically clears all "Re-Roll" history from the previous session, retaining only the currently selected result.

3. How to Hide Model Thinking Process

Problem: How to hide the "thinking process" displayed in model replies?

Solution:

Open the left sidebar.

Click the "More" option and select "Settings."

After entering the settings, select the "Chat Settings" tab.

Find the "Hide Model Thinking Process" switch and turn it on.

Effect Description:

After enabling, the model&#x27;s thinking process will no longer be displayed in the chat bubbles.

Note: This setting only affects the display and does not impact the model&#x27;s actual generation logic, timing, or effectiveness.
