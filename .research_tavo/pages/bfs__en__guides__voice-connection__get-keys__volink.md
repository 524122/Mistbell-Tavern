Volink API

To utilize Volink platform's AI voice model capabilities, the entire process mainly consists of two steps:

First, register an account on the Volink platform;

Second, create and securely store your API key within your account.

Below is the complete beginner-friendly guide for the Volink platform. Following the "register first, then obtain the key" approach, this guide will walk you through step-by-step from scratch, making it easy to get started.

1. Email + Verification Code Registration

Users can register by clicking "Login" on the Volink official website:

Visit https://volink.org and click "Sign in".

Enter a valid email address and click "Send code".

Check your email and click the verification link sent by Volink to complete email verification.

Once verified, you can access the Volink console and start using the service.

Features: No need to rely on third-party accounts; one-time setup and ready to use

2. Google Account One-Click Login

On the login page, click "Sign in with Google" to complete authorization via Google OAuth:

If registering for the first time using this method, the system will automatically create a Volink account linked to your email.

Subsequently, you can log in not only through the same Google account but also using the same Google email + verification code.

Advantages: No need to manually enter email verification codes, eliminating tedious steps; ideal for users already in the Google ecosystem

Steps to Obtain API Key

1. Go to the Homepage

Access the Volink website homepage and log in:volink.org

2. Access Account Details Page

Click on the API field in the bottom left corner

3. Navigate to API Key Page

On the API Key page, click "Create API Key" in bottom-right corner

Define a name for the key

Select "Create"

Finally, copy the key
