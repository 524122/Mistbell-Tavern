Doubao API

To utilize the AI model capabilities of the volcengine platform, the entire process primarily involves two steps:

First, register an account on the volcengine platform.

Second, create and securely store your API key within the account.

Below is the complete beginner's guide to getting started with the volcengine platform. Following the "register first, then retrieve the key" approach, this guide will take you from zero to fully operational with ease.

Doubao

Visit the VolcEngine official website

Registration Method 1:

Users can select "Mobile Phone Login/Registration" on the login page of the Doubao App or web version, enter their mobile phone number to receive an SMS verification code, fill in the verification code and (if needed) set a password to complete account creation and login.

Registration Method 2:

Based on partnerships with telecommunications carriers, users can click "One-Click Login" on the login page. With user consent, the system automatically calls the carrier's interface to complete mobile phone number verification, allowing for quick registration or login without manually entering a verification code.

Registration Method 3:

In the mobile or web version login box, select the "Apple ID Login" option. After authorizing access through Apple ID, the system will require further binding of a mobile phone number to verify identity. Once completed, users can skip the verification code and directly use Doubao.

Registration Method 4:

In environments supporting the Douyin (TikTok) ecosystem, users can click the "Douyin Login" or "TikTok Login" button. After authorizing Doubao to access public information and complete binding, users can create and log in to an account without additional verification codes or passwords.

Registration Method 5:

According to the user agreement, Doubao allows users to set a valid character combination as an account name and set a login password that meets security requirements. After filling these in during registration, the account is created; thereafter, users can log in directly using the account name and password.

Obtain API Key

Visit the VolcEngine official website and log in or register using your phone number or corporate email:
https://www.volcengine.com

Access the console and complete personal or enterprise identity verification as prompted (requires providing ID documents or enterprise credentials).

After logging in, click "Large Models" in the top menu bar, then select "Volcano Ark".

On the Volcano Ark page, scroll down to the "API Building" section and click "Start Now".

In the left-hand menu, navigate to "API Key Management" and click "Create API Key".Copy the generated API key and store it securely.

Click to activate management.

Find the large language model you need to activate, and click "Activate Service" to complete the activation.

After activation is complete, the status bar will display "Activated," and the corresponding large language model will be available for use.
