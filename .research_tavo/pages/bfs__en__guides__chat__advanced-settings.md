✦ Advanced Settings

In the chat interface, click the sidebar icon in the top-right corner to open the right-side function panel. Within the "Advanced Options" section of the panel, you can configure the following core settings:

Switch API Connection: Quickly change the API service or model used for the current conversation.

Enable/Switch Presets: Switch or enable different conversation preset templates to quickly alter the character's style or dialogue background.

Enable/Switch World Book: Switch or enable the background knowledge base (World Book) set for the current character to enrich their contextual information.

Enable/Switch Regex (Matching Rules): Switch or enable regular expression rules to achieve specific keyword triggers or automated responses.

Enable Long-Term Memory Function: Activate the long-term memory feature, allowing the character to remember and reference your important conversation information over extended periods.

Message Translation

Configure message translation and translate chat bubbles from the long-press action menu.

Group Chat

Create group chats, manage members, and choose how characters reply.
