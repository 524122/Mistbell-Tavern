Quick Reply in Group Chats

After enabling this feature, you can quickly trigger a specific character to speak in a group chat by clicking their avatar, simplifying the process of designating speakers in multi-character conversations.

Operation Path

Open the left sidebar.

Click the "More" option, find and select "Settings" in the expanded menu.

After entering the settings interface, select the "Chat Settings" tab.

In the chat settings, find "Quick Reply in Group Chats."

Function Description and Usage

Enable the Feature: Set the "Quick Reply in Group Chats" function switch to the "On" state.

Interface Changes: After enabling the feature, when you enter a group chat interface, avatar buttons for all current group chat members will be displayed in the top-left area of the input box.

Usage: After entering the content you want to say in the input box, simply click the avatar button of the target character to designate them to reply to your input—no need to type "@character name" commands.

Custom Shortcuts

With this feature, you can create and manage a set of personalized quick input phrases to rapidly enter frequently used content during chats, thereby improving conversation efficiency.
