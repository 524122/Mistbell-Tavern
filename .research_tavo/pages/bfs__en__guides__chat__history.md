Import & Export

Importing Chat History

Open the sidebar and click "+" - "Import Chat History", then select the chat History file exported from Chat Platform (with .jsonl file extension, you can search for "jsonl" extension in the folder to locate the file)

After selecting the file, import the chat Histories. The system will automatically match characters with the same name.

If there are no characters with matching names, you can manually select the corresponding character to import the chat Histories.

Detailed Steps

Open the sidebar, click the "+" button, and select "Import Chat Histories"

Choose the chat History file exported from Chat Platform (file format is .jsonl, you can search for "jsonl" extension in the folder to locate the file)

After selecting the file for import, the system will automatically match characters with the same name

If no matching character is found, you can manually select the corresponding character to complete the import

Export Chat History

Operation Steps:

In the chat interface, click the sidebar icon in the upper-right corner.

After calling up the right-side function panel, scroll to the bottom.

Find and click the "Export" button.

In the pop-up window, select the file format you wish to export (.txt, .json). After confirmation, the chat history file will be generated and saved.
