Custom Shortcuts

With this feature, you can create and manage a set of personalized quick input phrases to rapidly enter frequently used content during chats, thereby improving conversation efficiency.

Operation Path

Open the left sidebar.

Click the "More" option, find and select "Settings" in the expanded menu.

After entering the settings interface, select the "Chat Settings" tab.

In the chat settings, find and enter the "Custom Chat Shortcuts" submenu.

Function Description and Configuration

On this interface, you can:

Add Shortcuts: Create new shortcut entries and assign them an easily memorable label (e.g., "Greeting") and corresponding fill-in content (e.g., "Hello, how are you feeling today?").

Enable/Disable: Each shortcut entry has a toggle button on the right. The shortcut will only take effect when the toggle is switched on.

Usage: When the keyboard is invoked in the chat interface's input box, all enabled shortcut buttons will automatically appear above or near the keyboard area. Clicking any button will instantly fill the input box with its corresponding full content.

Image Sending

After enabling this feature, you can send images to characters. The AI model will recognize and describe the image content to facilitate conversation.

Quick Reply in Group Chats

After enabling this feature, you can quickly trigger a specific character to speak in a group chat by clicking their avatar, simplifying the process of designating speakers in multi-character conversations.
