Introduction

Tavo is a chat application designed specifically for AI role-playing. You can import your favorite character cards and use the most popular role-playing models available today, with no additional restrictions!

🤗 Rich character cards: Create your own characters from scratch or import cards from SillyTavern, supporting all popular character card websites

🔑 Private API: Connect directly to today's hottest models without middlemen marking up prices or imposing restrictions

👥  Group chat support: Whether for storyline roleplays, parties, or harems, multi-person chats are completely customizable - join the fun!

🎨 Chat theme customization: Freely design your preferred chat interface for maximum immersion!

🪓 Preset (Preset)importing: Import various community presets, whether for novel-style writing or jailbreaks - those who know, know (in development)

🚀 More features being unlocked continuously (our developers are working overtime ☕)...

Quick Start

When you first open the quick start screen, you can tap "One-click Setup" to complete the beginner guide.

Recommended for beginners: tap "One-click Setup" on the quick start screen and follow the guide to register Volink, create an API key, choose a model, and import the demo character.

Manual setup: If you already have an API key, go to API Settings and add the connection manually.

Create characters: Go to Role Management to create or import characters.

Start chatting: Head to Start Chatting and begin!
