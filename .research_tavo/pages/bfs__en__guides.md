I don't know where to start using Tavo for the first time? Don't worry, this Getting Started Guide will easily unlock your exclusive AI interactive experience! From importing characters and setting APIs to creating your ideal persona, you can get it done in a few steps and start an "AI adventure" that belongs only to you!

Beginners can start with "One-click Setup" on the quick start screen. It guides you through Volink registration, API key creation, model selection, and demo character import. Users who are already familiar with APIs can continue with the manual API setup tutorials in this guide.
