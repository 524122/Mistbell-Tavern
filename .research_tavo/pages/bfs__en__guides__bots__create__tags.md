Tags

“Character Tags (for classification & quick identification)”

What is this for?

👉 Uses a few keywords to quickly describe what kind of character this is.

Separate tags with commas

Does not affect chat behavior

Mainly for users to browse, filter, and recognize characters

How should you write them?

Think of this question:

“How would you describe this character in one short line?”

Examples:

teasing, flirty, daily-life, emotional, long-term RP

📌 Tips

5–8 tags is the sweet spot

Avoid full sentences—keep them short, scannable, and descriptive
