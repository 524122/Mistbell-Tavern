Nickname

“Nickname / Common Name Used in Group Chats”

What is this for?

👉 A friendly, casual name used only in group chat mode, making the character easier to recognize and address in multi-person conversations.

⚠️ Important Notes

The nickname applies only in group chats

It does not affect one-on-one chats

It does not replace the character’s main name

When is this useful?

The character participates in group chats

The character’s full name feels too formal for group settings

You want other users or characters to address them by a nickname in group conversations

Examples:

Tom 或 jerry

📌 Tips

This only affects group chat display and addressing

If you also want the nickname used in private chats, explicitly define self-reference in:

The character description

Opening messages
