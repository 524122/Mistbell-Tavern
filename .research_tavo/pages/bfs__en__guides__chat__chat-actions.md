Chat Operations

Filter Chat List by Character

You can use the character filter feature to quickly locate conversations with specific characters.

Operation Path

In the left "Menu Bar," click to open the "All Chats" list page.

Select the character name you wish to view.

Filter Effect

After selection, the chat list will display only all historical conversations you have had with that character, while conversations with other characters will be temporarily hidden.

Rename Chat Conversation

You can set a custom name for the current chat conversation to facilitate identification and management.

Operation Path

In the chat interface, locate the current conversation name at the top of the page.

Click on the name area.

Enter a new name and confirm to save.

Pin Chat Conversation

You can pin important conversations to the top of the chat list for quick access.

Operation Path

In the left "Menu Bar," browse and locate the chat conversation you need to pin.

On the conversation entry, click the "⋮" (More Actions) button that appears on its right.

In the pop-up action menu, select the "Pin" option.

Operation Effect

Once pinned, the conversation will always appear at the top of your chat list for the current character, unaffected by new message sorting.

View Conversation Statistics

This feature helps you review the overall data overview of the current conversation, including companionship duration, interaction volume, and content scale.

Operation Path

In the chat interface, click the button in the upper-right corner to open the right "Menu Bar."

In the pop-up menu, scroll to the bottom.

Click the "Statistics" option.

Statistical Information Description

The page will display detailed statistical data for the current conversation, mainly including:

Days of Companionship: The total number of interaction days since the conversation was created.

Number of Messages from Both Sides: The total number of messages sent by you and the character.

Total Word Count of Chat: The cumulative text volume generated in the current conversation.

Restart Current Chat

This operation will clear all historical records of the current conversation and start a brand-new session based on the same character and parameters.

Operation Path

In the chat interface, click the button in the upper-right corner to open the right "Menu Bar."

In the pop-up menu, scroll to the bottom.

Click the "Restart Chat" option.

Important Notes

After performing this operation, the chat history will be permanently deleted and cannot be recovered.

If no adjustments are made, basic configurations such as character settings, model parameters, and system prompts will remain unchanged.

A new blank session will begin immediately.

Clone Chat Conversation

This operation will fully copy all content (including history) of the selected conversation and generate an independent, identical new conversation copy.

Operation Path

In the chat list of the left "Menu Bar," locate the target conversation you need to clone.

On the conversation entry, click the "⋮" (More Actions) button that appears on its right.

In the pop-up menu, select the "Clone Chat" option.

Operation Result

An identical new conversation will be generated immediately and displayed in your chat list. You can freely continue the conversation or experiment with different branches on this copy without affecting the original conversation.

Delete Chat Conversation

This operation will permanently delete the specified conversation entry and all its chat history. Please proceed with caution.

Operation Path

In the chat list of the left "Menu Bar," locate the target conversation you need to delete.

On the conversation entry, click the "⋮" (More Actions) button that appears on its right.

In the pop-up menu, select the "Delete" option.

Important Notes

After performing this operation, the conversation and all its content will be permanently deleted and cannot be recovered.

A confirmation dialog will pop up. Please confirm again to prevent accidental operation.

View Character Historical Chats

This feature is used to centrally view all historical conversation records you have had with a specific character.

Operation Path

In the left "Menu Bar," scroll to the bottom and enter the "Characters" page.

In the character list, locate the target character you wish to view.

Click the "⋮" (More Actions) button on the right side of that character entry.

In the pop-up menu, select the "Historical Chats" option.

Operation Result

The page will redirect and display a list of all historical conversation entries with that character. You can click on any conversation in this list to view the complete past chat content.
