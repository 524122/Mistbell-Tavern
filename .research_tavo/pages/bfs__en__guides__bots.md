Open the app and click the "Menu Bar."

Click the "Character" button.

Click "Create."

On this page, you can choose to create a new character or select an import method.

Add a character avatar, fill in the character name and description, then click "Save" to create the character.

JSON Import: Select a file to import a character card. Click "Import from File" and choose the JSON file to upload.

After importing the character, click "Save" to complete the process.

Image Import: Import a character card using an image. Click "Import from Photo Library" and select the PNG image to upload.

After importing the character, click "Save" to complete the process.

If the following message appears, it means the PNG image does not contain any text blocks. Please try importing another PNG image.

Import from URL: Enter the character URL link (only single links are supported) and click "Import."
(Note: Some imports may fail if the character is private and not authorized for the platform.)

After importing the character, click "Save" to complete the process.
