Backup

You can use this feature to back up your core data (including API keys) and restore data from backup files at any time to ensure the security of your data configuration.

Operation Path

Open the left sidebar.

Click the "More" option, find and select "Settings" in the menu.

After entering the settings interface, select the "Backup and Restore" tab.

Core Functions

After entering, you can use the following functions:

Data Backup: Create a complete data backup file. The backup content can optionally include your API keys.

Backup Reminder Settings: Set up periodic backup reminders to help you develop a regular backup habit.

Restore Data: Select an existing backup file to import, allowing you to restore the data (including API keys and configurations) to the state at the time of backup.

Important Note: Version Compatibility

Please Note: Backup files created by a higher-version application cannot be restored in a lower older version of the application.

Recommended Action: Before restoring data, ensure your application is updated to the latest version, or at least to a version not lower than the one used to create the backup file, to avoid restoration failure.

Storage Space

You can use this feature to view detailed information about the storage space used by the application and perform targeted data cleanup to free up device space.

Image Sending
