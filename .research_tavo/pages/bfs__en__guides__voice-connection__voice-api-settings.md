Voice API Settings

Operation Path

Open the left sidebar.

Click the "More" option, then find and select "Voice" from the menu.

After entering the voice settings interface, select the "Voice API" option.

Click the "New" button in the top-right corner of the interface.

In the new configuration window:
◦ Select the voice model platform you want to use.
◦ Enter the corresponding API key for that platform.
◦ Choose a suitable voice model.
◦ Click "Save" to complete the configuration.

Connection Troubleshooting

If "Connection Failed" is displayed when saving: Please check your network connection, enable the proxy (VPN), and try saving again.

If "Save Successful" is displayed: It means the Voice API connection has been successfully established and can be used for subsequent speech synthesis.
