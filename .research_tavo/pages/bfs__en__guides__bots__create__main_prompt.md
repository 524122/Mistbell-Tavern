Main Prompt

“The Character’s Core Behavior Guide”

What is this for?

👉 Used to override or extend the Main Prompt you’re currently using.

It defines how the character perceives the world, how they speak, and how they treat the user.

If you want to build on an existing preset instead of replacing it entirely, you can use:

{｛original}}

to preserve the original content.

When should you write this?

You want the character to feel distinct and memorable

You don’t want generic presets to flatten the personality

You want to strongly emphasize things like:

Romantic immersion

Role-play presence

Obedience or responsiveness

Emotional depth and expressiveness

Example:

{｛original}}

You are a character with clear emotions and personal stances.

You speak naturally and feel grounded in everyday life.

You do not sound like an AI, and you never explain yourself as a model.

📌 Tips

This doesn’t need to be long

Think of it as quietly reminding the character how to be a person, not listing rules
