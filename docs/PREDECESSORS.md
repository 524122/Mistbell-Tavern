# 前辈借鉴清单（OMate / Tavo）

> 2026-08 调研。两位均为**移动端 AI 角色扮演前辈**（闭源 app，仅功能面/文档面借鉴——参考纪律适用，无代码可抄）：
> - **OMate Chat**（help.omate.org 官方手册 + 更新日志全量调研）：BYOK + 深度 ST 生态兼容 + 创作者工具链 + 发现页开放协议
> - **Tavo**（docs.tavoai.dev 188 页全扫）：宏引擎分层 + EJS/插件/MCP 移动扩展栈 + 完全本地化隐私承诺
>
> 关联：[ROADMAP.md](ROADMAP.md) / [SETTINGS.md](SETTINGS.md) / [MODES.md](MODES.md) / [FOUNDATION.md](FOUNDATION.md)

## 核心结论

两位前辈共同验证的最大缺口：**宏引擎是生态卡"能真正跑起来"的底线**——ST 生态卡几乎每张都用
`{{char}}/{{user}}/{{persona}}/{{random}}/{{roll}}`，我们的 PromptBuilder 目前零替换（导入的卡会把
`{{user}}` 原样发给模型）。这比任何新功能都优先。

## 立即吸收（F2.1 批次：生态卡最后一公里）

| 借鉴点 | 来源 | 落点 | 成本 |
|---|---|---|---|
| **宏引擎 Tier1+Tier2**：`{{char}}/{{user}}/{{persona}}/{{description}}/{{scenario}}/{{time}}` 系列 + 旧名别名兼容；`{{random::a::b}}`、`{{roll::3d6}}`；`{{#if 宏}}…{{/if}}` 仅非空判断（不做 else/比较——Tavo 验证单一非空覆盖多数需求）；**未知宏原样保留 + 字段级错误回退**（坏卡不崩会话） | Tavo 宏文档 | 新 `util/MacroEngine.kt` 纯函数（可单测），PromptBuilder 各字段渲染前统一 pass；生效位置：角色定义/首条消息/世界书条目/历史后指令 | 中 |
| **导入转化报告**：每次导入列出"完整/降级/暂缓"字段清单（如 keysecondary 未映射、extensions 已透传） | OMate | CardParser 返回诊断列表，导入 UI Snackbar→详情 | 低 |
| **上下文调试面板**：显示每次请求实际发出的系统提示词/世界书激活条目/宏替换结果/token 统计 | OMate | 升级现有 PromptPreviewScreen 为"实际请求快照"（排障刚需） | 低 |
| **think 标签过滤**：`<think>` 推理文本在发给 API 前剔除、气泡内折叠显示（思考型模型必配） | OMate | 流式渲染层 + PromptBuilder 历史清洗 | 低 |

## 中期吸收（并入既有批次）

| 借鉴点 | 来源 | 归属批次 |
|---|---|---|
| **双层记忆之 FTS 全文检索**：SQLite FTS 检索历史对话（Android 内建、零依赖），配过滤策略（剔 statusBar/think/HTML/emoji 噪声）——比 BM25 伪向量**诚实**且即刻可用 | OMate | **F3 增补**：FTS 先行做"诚实的词法检索"，ONNX 语义向量随后（两条腿走路，FTS 可先上线） |

| **撤销回滚记忆**：undo 最后一条时同步回滚已提取的记忆（避免记忆污染） | OMate | 消息操作批次（我们已修 undo 计数回写，补记忆回滚） |

| **状态栏 `<statusBar>` 标签 + 事件书（JSON Schema 已公开）** | OMate | 模式② 规则包的具体形态参考（数值/任务系统的移动端轻量解） |
| **宏助手 UI**（输入框点选插入宏面板） | Tavo | 宏引擎落地后的配套（手机端无键盘提示，点选是唯一路径） |

## 借鉴原则重申

两位前辈均闭源——本清单全部为**功能面/产品面参照**（官方文档公开表述），无任何代码参照；
OMate 的发现页协议与事件书 Schema、Tavo 的宏语法均为公开文档描述的互操作格式，
按"格式可自由实现"原则自研实现（参考纪律）。
