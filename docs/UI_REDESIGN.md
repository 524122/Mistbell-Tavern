# Mistbell Tavern UI 重设计

## 目标

这次重设计解决的是使用感，而不是再增加功能数量：用户进入应用后能快速找到最近会话，知道下一步该做什么，且在聊天、角色、设置之间保持同一套视觉规则。

## 视觉方向：雾灯酒馆

- **背景**：深墨色或暖灰色，降低大面积纯黑/纯白带来的刺眼感。
- **主色**：暖琥珀，只用于主操作、选中状态和重要提示。
- **辅助色**：灰绿表示正常状态，砖红表示危险操作，避免彩色图标各自为政。
- **表面**：卡片使用低对比度和细描边，减少阴影堆叠。
- **形状**：小控件 8dp，中型卡片 16dp，主容器 20dp；不再每个组件使用不同圆角。
- **文字**：页面标题 22sp，内容 14–16sp，辅助信息 11–12sp；标题和正文之间靠留白建立层级。

## 信息架构

### 主导航

保留四个稳定入口：

1. **会话**：最近对话、搜索、导入、新建。
2. **角色**：角色卡、创建角色、角色级主题。
3. **世界书**：独立世界书和条目管理。
4. **设置**：API、外观、记忆、备份和关于。

导航只负责切换一级内容，不承载删除、导出等上下文操作。

### 会话页

- 顶部标题改为“会话”，副标题告诉用户当前页面用途。
- 主操作固定为“新建对话”，使用带文字的 Extended FAB，不再用需要二次点击的展开 FAB。
- 导入是顶栏次要操作。
- 会话卡片只呈现：头像、标题、最后消息、时间、未读/置顶状态；批量删除、改名、导出放入上下文菜单。

### 聊天页

- 顶部只保留角色信息、提示词预览和会话菜单。
- 消息正文使用更大的行高和更低对比的气泡边界，重点放在文本内容。
- 输入区保持一个主动作，停止生成、切换开场白等动作只在对应状态出现。

### 设置页

- 每组设置使用同一个低对比度容器和统一行高。
- 首屏只显示 API 状态、对话、外观、记忆和数据管理。
- 高级采样参数与实验功能继续折叠。

## 组件规则

| 组件 | 默认状态 | 交互状态 | 注意事项 |
|---|---|---|---|
| 主按钮 | 琥珀填充 | 颜色加深 | 一页只保留一个主按钮 |
| 次按钮 | 透明 + 描边 | 背景轻微变深 | 不和主按钮抢视觉重量 |
| 卡片 | surface + 1dp 描边 | primaryContainer 或 tonalElevation | 阴影保持为 0 |
| 顶栏 | background | 滚动后显示细分割线 | 不使用大面积彩色标题栏 |
| 导航项 | 低对比图标 | 胶囊选中指示器 | 图标和文字保持同一颜色层级 |

## 实施顺序

1. 设计令牌：颜色、字体、形状、间距。
2. 公共组件：顶栏、设置分组、导航项、空状态。
3. 会话页：列表卡片、主操作、导入入口。
4. 聊天页：消息气泡、输入区、上下文菜单。
5. 角色页和世界书页：统一卡片与空状态。
6. 设置页：折叠层级和危险操作确认。

本轮先完成第 1–3 步，业务 ViewModel、数据库和 API 链路保持不变。
