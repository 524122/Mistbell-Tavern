# 群聊 @提及功能使用指南

## 📋 功能概述

为群聊模式添加了 **@提及** 功能，可以在消息中指定特定角色来回复，增强多角色对话的互动性。

---

## ✨ 功能特性

### 1️⃣ **@提及输入**
在输入框中输入 `@` 后，会自动触发角色选择：

```
输入：@
结果：显示所有参与者列表

输入：@艾
结果：过滤显示名称包含"艾"的角色
```

### 2️⃣ **智能自动补全**
- **实时过滤**：根据输入内容动态筛选角色
- **弹窗选择**：输入框上方显示匹配的角色列表
- **点击补全**：点击角色名自动完成输入

### 3️⃣ **多角色提及**
可以在一条消息中提及多个角色：

```
@艾莉丝 你觉得呢？@Bob 你怎么看？
```

---

## 🎯 使用方法

### 基础用法

1. **进入群聊会话**
2. **在输入框输入 @**
3. **从弹出列表中选择角色**
4. **继续输入消息内容**
5. **发送消息**

### 示例对话

```
用户：@艾莉丝 今天天气怎么样？
AI(艾莉丝)：今天是个晴朗的好天气！

用户：@Bob 你觉得呢？
AI(Bob)：我同意艾莉丝的看法。

用户：@艾莉丝 @Bob 我们一起去郊游吧
AI：(两位角色都会注意到这条消息)
```

## 🔧 技术实现

### 前端实现

#### 1. **MentionSupport.kt** - 核心逻辑
```kotlin
// 解析消息中的 @提及
fun parseMentions(text: String): List<String>

// 检测当前是否在输入 @
fun detectMentionInput(text: String, cursorPosition: Int): String?

// 过滤匹配的角色
fun filterCharacters(characters: List<Character>, query: String): List<Character>

// 替换文本中的 @ 提及
fun replaceMention(text: String, cursorPosition: Int, characterName: String): Pair<String, Int>
```

#### 2. **MessageInput.kt** - UI 组件
```kotlin
@Composable
fun MessageInput(
    onSend: (String) -> Unit,
    enabled: Boolean = true,
    isGenerating: Boolean = false,
    onStop: (() -> Unit)? = null,
    participants: List<Character> = emptyList(), // ← 新增参数
)
```

#### 3. **MentionSuggestionPopup** - 自动补全弹窗
- 位置：输入框上方
- 样式：圆角卡片 + 阴影
- 最多显示：5 个匹配结果
- 交互：点击选择 / 点击外部关闭
