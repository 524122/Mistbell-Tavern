# 群聊自动模式功能说明

## 📋 功能概述

参考 SillyTavern（酒馆）的设计，为群聊模式添加了**自动对话模式**和**智能停顿提示**功能。

## ✨ 新增功能

### 1️⃣ **自动对话模式**

**位置**：聊天界面输入框上方（仅群聊模式显示）

**控制栏包含**：
- ✅ **开关**：勾选后自动循环生成对话
- ⏱️ **间隔调节**：可设置 1-60 秒的延迟时间
- ➕➖ **快捷按钮**：快速调整间隔秒数

**工作原理**：
```kotlin
// 开启后，后台循环执行
while (自动模式开启 && 群聊模式) {
    if (!正在生成) {
        continueGroupChat()  // 调用继续对话
    }
    delay(设定的秒数)
}
```

**适用场景**：
- 🎭 多角色自由发挥
- 🎬 观看 AI 角色互动
- 🧪 测试群聊对话逻辑

---

### 2️⃣ **智能停顿提示**

**触发条件**：
- ✅ 群聊模式
- ✅ 非生成中状态
- ✅ 自动模式关闭
- ✅ 距上条消息 > 3 秒

**UI 表现**：
```
┌─────────────────────────────────────┐
│ ℹ️ 对话似乎停顿了...    [让AI继续] │
└─────────────────────────────────────┘
```

**设计理念**：
- 📊 被动提示，不打扰正常对话
- 🎯 精准判断停顿时机
- 🚀 一键快速恢复对话

## 📝 使用说明

### 启用自动模式

1. 进入**群聊会话**
2. 在输入框上方找到**自动对话**开关
3. 点击开关，开始自动对话
4. 使用 ➕➖ 调整间隔时间

### 手动继续对话

1. 等待 3 秒后出现提示卡片
2. 点击 **[让AI继续]** 按钮
3. AI 会选择最合适的角色接话

---

## ⚠️ 注意事项

1. **自动模式仅在群聊时可用**（Classic 模式不显示控制栏）
2. **生成中会自动暂停**（避免并发冲突）
3. **切换会话会自动关闭自动模式**（防止误操作）
4. **延迟时间范围 1-60 秒**（防止过快或过慢）
