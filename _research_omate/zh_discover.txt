#
定制发现页面
你可以通过提供JSON文件来定制发现页面。在「设置」→「发现页设置」中，可以添加发现页API地址。
OMate APP会访问
发现页API地址/cards.json
来读取卡片列表。
比如目前官方的发现页的JSON文件地址是：
https://store.omate.org/oc/cards.json
其格式定义如下：
cards:
[
{
"id": "1742218048477",
"name": "苏墨",
"fileName": "1742218048404-苏墨.png",
"filePath": "uploads/1742218048404-苏墨.png",
"coverPath": "uploads/1742218048404-苏墨-cover.jpg",
"fileType": "png",
"uploadTime": "2025-03-17T13:27:28.477Z",
"gender": "female",
"intro": "手绘设计师，倔强又敏感，在AI浪潮中坚持自我，用画笔描绘情感与梦想。",
"description": "苏墨，一位20岁的中国现代女性。",
"personality": "",
"stories":
[
{
"path": "uploads/stories/1741855693696-E88B8FE5A2A8-C3A5C2A4C28DC3A5C288C2BBC3A4C2BAC2BAC3A7C294C29FC382C2B7C3A4C2B8C28A.multi.h2book.json",
"name": "复刻人生·上.multi.h2book.json",
"uploadTime": "2025-03-13T08:48:13.702Z"
}
]
},
... 其他卡片
]
其中：
coverPath
是卡片的封面图片路径
filePath
是卡片的图片路径(其中包含了角色信息)
stories
是卡片的故事书列表
这些路径都是相对于
发现页API地址
的。比如
coverPath
是
uploads/1742218048404-苏墨-cover.jpg
，而
发现页API地址
是
https://store.omate.org/oc
，那么
coverPath
的完整路径就是
https://store.omate.org/oc/uploads/1742218048404-苏墨-cover.jpg
。
