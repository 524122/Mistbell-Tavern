#
API设置
OMate支持连接到AI服务提供商，通过配置API设置，您可以使用自己的API密钥来访问这些服务。
注意
理论上，支持OpenAI规范和Claude规范的API都可以，但因为各个服务商对API的支持程度不同，部分服务商的API下，OMate可能无法正常工作。
#
API配置列表
API配置列表页面展示了您已配置的所有API连接。每个API配置卡片包含以下信息：
API名称
API规范（
API密钥（部分隐藏）
#
添加新API配置
添加一个新的API配置：
导航至"设置"页面
在"API设置"部分，点击"+"按钮
在弹出的对话框中填写以下信息：
#
必填信息
名称
：为此API配置命名
API规范
：支持OpenAI接口规范，1.0.13+支持Claude接口规范（仅聊天和总结模型）
API密钥
：输入您的API密钥
提示
您可以点击右下角的浮动按钮快捷填写配置
提示
您可以在服务提供商的官方网站上获取API密钥。如果提供商有申请链接，系统会在表单中提供快捷访问按钮。
警告
请妥善保管您的API密钥，不要与他人分享。OMate只在本地存储您的API密钥，不会将其上传到任何服务器。
#
编辑API配置
您可以随时编辑已创建的API配置：
在API配置列表中，向左滑动API卡片
系统会自动进入编辑模式
修改需要更新的信息
点击"保存"按钮应用更改
#
删除API配置
如果您不再需要某个API配置，可以将其删除：
在API配置列表中，向右滑动API卡片
系统会提示确认删除
按提示输入后点击确认按钮完成删除
注意
系统要求至少保留一个API配置。如果只剩最后一个API配置，您将无法删除它。
#
活跃API配置
系统会自动将新添加的API配置设置为活跃状态：
当您添加新API配置时，系统会将其设置为活跃
活跃的API配置将用于所有需要API的功能
在聊天设置中，您可以为特定对话选择不同的API配置
#
发现页API设置
除了主API设置外，OMate还提供了发现页API设置：
导航至"设置"页面
点击"发现页设置"
在API地址设置中，您可以：
添加新的API地址
编辑现有API地址
调整API地址的优先顺序
提示
发现页API地址用于从远程服务器获取内容，如角色卡片等。系统会按照设置的顺序尝试连接API地址，并合并获取的数据。
#
请求超时设置
设置 → 聊天设置中可调整
请求超时时间
（全局生效，默认 10 分钟）。使用响应较慢的思考型模型或不稳定的中转站时，可适当调大避免长回复中途断开。
#
附加参数（chatModelParams）
API 配置的「模型参数」栏支持以查询串格式传入附加请求参数，如
max_tokens=2048&top_p=0.9
。常用键：
max_tokens
：单次回复的输出 token 上限（注意与「最大上行字数」不同，后者限制的是发送出去的内容量）
top_p
、
frequency_penalty
等采样参数：按所选服务商支持情况透传
