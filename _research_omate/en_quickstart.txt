#
Quick Start
Welcome to OMate! This guide will help you get started quickly and begin conversing with AI.
#
0. Apply for API
To use OMate, you need to provide your own API key from an AI platform. If you already have an API key, you can skip this step.
In theory, interfaces compatible with the OpenAI specification can be used, but compatibility issues may exist. We recommend using official services or other service providers we recommend.
&#x1F388;
Click here to watch the video tutorial for the subsequent steps
#
1. Configure API
When using OMate for the first time, you need to configure the API:
Enter the settings page
Swipe left on the API Settings card
Enter your API key (note that clicking the floating button in the bottom right allows you to quickly fill in preset service provider configurations)
Save settings
#
2. Import Character
With the API configured, you can start creating or importing AI characters:
Go to the discovery page
Click on a character card you like
Click "Import"
Set an avatar and save the card information
#
3. Start Conversation
Now you can start conversing with the AI:
Select the character you created from the character list
Click on the card to create a conversation
Type your message in the input box
Click send to start chatting
