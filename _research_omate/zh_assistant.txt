#
小M同学（内置助手）
小M同学是 OMate 的内置 AI 助手：
短按悬浮球
呼出。它能回答应用使用问题，也能直接帮你查看和操作应用里的数据（查角色、世界书、预设，帮你挂载预设、绑定世界书）。
小M使用你当前
激活的 API 配置
回答问题——它和聊天角色一样是 BYOK 的，不产生额外服务费用。没配 API 时它会引导你先完成配置。
#
呼出方式
短按悬浮球
→ 小M面板（半屏对话）
长按悬浮球
→ 创作者模式
两个手势可在设置中互换。
