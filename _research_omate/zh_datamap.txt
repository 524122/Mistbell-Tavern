#
数据存储地图
本页面向 AI 助手（小M）：回答「我的数据存在哪」「备份会带上什么」「删了会怎样」类问题的依据。所有数据都在
用户设备本地
，OMate 不上传。
#
1. 三类存储
flowchart LR
A[SQLite 数据库] --- A1[聊天/消息/朋友圈/世界书/预设/挂载/KV/LivePage/MCP]
B[SharedPreferences] --- B1[API配置/角色列表/面具/注入提示词/知识书元数据/各类设置项]
C[应用文档目录文件] --- C1[头像与背景等媒体/知识书向量数据/历史归档/导出文件]
#
2. SQLite 主要表
表
存什么
备注
chats
对话元数据 + 配置 JSON（含角色快照、API 快照、各类开关）

快照制

live_pages / mcp_servers
LivePage 页面、MCP 服务器配置
#
3. SharedPreferences（键值配置）
API 配置列表（含密钥，仅本机）、角色配置列表、面具列表、注入提示词、知识书元数据、全局聊天设置（历史条数/最大上行字数/相似度阈值/请求超时等）、主题与界面偏好、悬浮球手势设置、朋友圈自动生成配置等。
#
4. 常见问答依据
「备份与恢复」
（设置 → 备份与恢复）覆盖数据库与配置；恢复后建议重启应用。
「删除角色会删对话吗？」
不会——对话持有角色快照，独立存在；但新对话无法再选到该角色。
「密钥安全吗？」
API 密钥只存在本机 SharedPreferences，不进备份分享文件、不进预设（预设只存 API 配置的
引用 ID
）。
「换手机怎么迁移？」
用备份与恢复导出/导入；媒体文件（头像/背景）在应用文档目录，随备份打包。
