#
Mask Function
The mask function allows you to set your own role identity in conversations, enabling richer and more personalized interactions with AI characters.
#
Purpose of Masks
In OMate, masks represent the user&#x27;s own role settings:
Users can define their character traits through masks
Masks work together with AI characters to create a more immersive conversation experience
The system applies mask settings in chats to form specific conversation scenarios
#
Managing Masks
#
Accessing the Mask List
Enter the "Settings" page
Click on the "Mask List" option
View all created masks
#
Creating a New Mask
On the mask list page, click the "+" button in the top right corner
Fill in the following information:
Name
: The name of the mask (required)
Avatar
: Upload a profile picture for the mask (required)
Description
: The character setting of the mask (required)
Click the "Save" button to complete creation
#
Editing Masks
In the mask list, swipe left on the mask card to access the option button
Modify the mask information
Click the "Save" button to apply changes
#
Deleting Masks
In the mask list, swipe right on the mask card to access the option button
Enter "delete" in the confirmation dialog
Click the "Delete" button to confirm the operation
Deleting a mask cannot be undone. After deletion, you will not be able to recover the mask settings.
#
Activating Masks
In the mask list, click the "Activate" button
The system will deactivate other masks and activate the selected one
Only one mask can be activated at a time, or no mask at all
#
Applying Masks in Conversations
#
Selecting a Mask When Creating a Conversation
When creating a new conversation, you can select an existing mask
The system will apply the mask settings to the conversation
The AI character will adjust its interaction style based on your mask settings
#
Modifying Masks in Conversations
In the conversation interface, click the settings button
Enter the conversation management page
Select or change the mask
Save settings to apply changes
#
Mask Setting Tips
#
Writing Effective Mask Descriptions
Clearly describe the character traits you want to portray
Include the character&#x27;s background, personality, and speaking style
Add specific ways to interact with AI characters
Avoid overly complex or contradictory settings
#
Mask and Character Pairing
Try to choose mask settings that complement the AI character
Create masks for specific scenarios, such as a "student" mask to pair with a "teacher" character
The mask description will be used as part of the system prompt, guiding how the AI interacts with you
