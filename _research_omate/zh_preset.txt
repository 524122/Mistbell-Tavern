#
预设
预设是一组
可叠加的配置覆盖
：把模型、温度、系统提示词、提示词分组、世界书挂载等打包成一份，需要时整套启用。典型用法：
「日常聊天」用便宜模型，全局挂一个「日常」预设；
某个角色固定用某个中转站 + 某套调教方案（挂在角色上）；
朋友圈生成固定用轻量模型（挂在朋友圈上）；
临时开一局特殊玩法，挂到单个对话，聊完关掉。
#
入口
预设库
（新建/编辑/删除/全局挂载）：设置 → 高级设置 → 预设
各场景的预设栈
：
单个对话：对话管理 → 基础设置 → 预设区块；或聊天页右上 ⋮ 菜单 → 预设（可加星固定到顶栏）
角色：角色编辑页 → 预设区块
故事：故事设置页底部
朋友圈：朋友圈设置页底部
#
新建与编辑
预设库右上角「+」新建。编辑器按分类列出所有
可预设的配置项
，每项一个开关：
开关
开
= 该项参与生效（下方出现值编辑器）；
开关
关
= 值保留但不生效（临时停用某项而不丢值）。
也可以从预设 JSON 文件导入（「角色」页 + → 导入，自动识别）。
#
预设栈：多预设叠加
每个场景是一条
栈
：可挂多个预设、拖拽排序、逐条启停。规则一句话：
越靠上优先级越高，自上而下覆盖
。
不同场景的栈互相独立（同一个预设在对话栈和全局栈里的顺序可以不同）。栈的编辑
即时保存
，聊天场景下一条消息立即生效。
高阶：多处冲突时谁说了算
同一个配置项被多处设置时，优先级从低到高：
代码默认值 → 全局设置手填 → 对话配置手填 → 全局栈 → 角色栈/功能栈 → 对话栈
栈内则是
上面的赢
。两点例外：
提示词分组、世界书挂载、知识书是
并集
语义——只加不减，不会互相覆盖；
预设不修改你的原始配置，只在发送时生效——移除挂载即恢复原样。

预设解析机制
。要点速查：
# 优先级判定（同一 scalar 键）  (verified: v1.9.7)
effective = chat_stack_top  or role_or_app_stack_top  or global_stack_top  or manual_value
# listUnion 键（injectionGroups/worldbook.mounts/knowledge.books）：所有层取并集

全库无任何挂载时门禁短路，行为与无预设完全一致。
