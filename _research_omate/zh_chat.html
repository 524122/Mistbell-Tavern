# 聊天功能

OMate的聊天功能让您可以与AI角色进行自然、流畅的对话交流，创造独特的互动体验。

# 对话列表

对话列表页面展示了您的所有聊天记录，按照最近活动时间排序。每个对话卡片包含以下信息：

  • 角色头像
  • 对话标题
  • 最近消息预览
  • 最后更新时间

# 开始新的对话

创建一个新的对话非常简单：

  1. 导航至"对话"页面
  2. 点击右上角的"+"按钮
  3. 在弹出的对话框中：
    • 输入对话标题（系统会基于角色和面具自动生成）
    • 选择一个角色
    • 选择面具（可选）
    • 选择API配置
  4. 点击"创建"按钮开始对话

# 聊天界面

聊天界面设计简洁直观，包含以下元素：

  • 消息区域：显示您与AI角色的对话内容
  • 输入框：用于输入您的消息
  • 发送按钮：发送您的消息
  • 设置按钮：提供对话管理选项
提示

您可以左右滑动任何消息气泡进行编辑或删除操作。

# 管理对话

# 查看历史对话

您可以随时查看和继续之前的对话：

  1. 在对话列表中点击任一对话
  2. 系统将加载完整的对话历史
  3. 您可以继续与AI角色交流

# 非角色扮演模式

在非角色扮演模式下，输入框左侧会出现一个「新话题」的图标，点击后可以开始一个全新的话题。旧的话题则自动保存为聊天历史。

  1. 点击右上角的更多按钮
  2. 点击"查看聊天历史" 即可查看历史对话

# 删除对话

如果您不再需要某个对话，可以将其删除：

  1. 在对话列表中，滑动对话卡片
  2. 点击"删除"按钮
  3. 在弹出的确认对话框中输入"delete"
  4. 点击"删除"按钮确认操作
警告

删除对话操作不可撤销。

# 对话设置

您可以自定义每个对话的设置：

  1. 在聊天界面，点击右上角的设置按钮
  2. 在对话管理页面中，您可以：
    • 修改对话标题
    • 调整角色和面具设置
    • 查看和管理对话历史
    • 调整API设置

# 消息流式响应

OMate使用流式响应技术，让AI回复更加自然流畅：

  • 消息会像人类打字一样逐字显示
  • 您可以在AI回复过程中提前阅读内容
  • 流式响应让对话节奏更自然

# 角色问候设置

OMate支持角色的多种问候语设置：

  • 首条消息：角色的标准第一条消息
  • 备选问候语：多条可随机选择的问候方式
  • 系统会在对话开始时自动选择合适的问候语展示

# 对话管理页新增设置

对话管理（聊天页右上角齿轮）近期新增的设置项：

  • 显示模型思考（基础设置）：打开后，思考型模型的推理过程会包在思考折叠块里显示；默认关闭，只看最终回复。
  • 昵称文字色（界面标签）：用户与角色的昵称可分别自定义颜色；使用自定义背景但未设置颜色时，会按背景明暗自动选择对比色，保证可读。
  • 预设（基础设置底部）：本对话的预设栈，详见预设。
  • 世界书临时启停（Prompt 标签）：临时关闭某本世界书，只影响本对话。

# 上下文与思考日志

聊天页 ⋮ 菜单 →「上下文与思考日志」（可加星固定到顶栏）能看到每次请求实际发送了什么：系统提示词、世界书激活情况、知识库检索结果、宏替换结果等。排查「AI 为什么不知道 XX」时先看这里。

每次发送，OMate 按固定顺序组装上下文（简版）：

flowchart TD
    A[你点发送] --> B[应用预设栈覆写]
    B --> C[全局提示词 + 注入提示词]
    C --> D[世界书扫描注入]
    D --> E[角色设定链<br>描述/性格/场景/示例]
    E --> F[记忆与知识库检索]
    F --> G[历史消息按预算裁剪]
    G --> H[宏替换 → 发出请求]

各环节的开关位置与完整细节见 聊天上下文管线。两个最常用的结论：

  • 历史消息数量限制的是真实对话条数，注入内容不占这个额度；
  • 最大上行字数是总预算，系统消息与知识库优先占用，塞不下的最旧历史被丢弃（会提示）。
