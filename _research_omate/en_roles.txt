#
Character Management
Characters are one of the core features of OMate, allowing you to create AI characters with unique personalities and backgrounds and engage in deep conversations with them.
#
Character List
The character list page displays all the characters you have created. Each character card contains the following information:
Character avatar
Character name
Character brief introduction
#
Creating a New Character
There are multiple ways to create a new character:
Navigate to the "Characters" page
Click the "+" button in the top right corner, select one of the following methods:
Create New Character
: Create a new character from scratch
Import Character
: Import an existing character from a file
Import URL
: Import a character via URL
Tip
When the network is slow, importing through URL or from the discovery page may take a longer time. Please be patient.
#
Basic Information
Name
: The character&#x27;s name
Avatar
: Upload or select an image as the character&#x27;s avatar (optional)
Introduction
: A brief description of the character
#
Character Settings
First Message
: The character&#x27;s initial greeting
Alternative Greetings
: Multiple greetings that can be used randomly (one per line)
Personality Traits
: The character&#x27;s personality, habits, and behavior patterns
Scene Setting
: The environment and situation the character is in
Conversation Examples
: Sample dialogues of the character, showcasing language style
System Prompt
: System instructions guiding how the AI should play this character
Post-History Instructions
: Additional instructions added after the conversation history
Tip
Detailed character settings help the AI better understand and portray the character, providing a more consistent and immersive conversation experience.
#
Editing Characters
You can edit your created characters at any time:
In the character list, swipe left on a character card
Click the "Edit" button
Modify the information you want to update in the popup dialog
Click the "Save" button to apply the changes
#
Deleting Characters
If you no longer need a character, you can delete it:
In the character list, swipe right on a character card
Click the "Delete" button
Type "delete" in the confirmation dialog that appears
Click the "Delete" button to confirm the operation
Deleting a character cannot be undone. After deleting a character, all related conversation records will still be retained, but you cannot have new conversations with that character.
#
Character Import Feature
OMate supports multiple ways to import characters:
#
Import Local Files
On the character page, click the "+" button and select "Import Character"
Choose a local character card file in JSON or PNG format
Confirm the character information and save
#
Import via URL
On the character page, click the "+" button and select "Import URL"
Enter the URL address containing the character data
Confirm the character information and save
#
Compatible with Multiple Character Formats
OMate supports various character card formats:
Character Card V1
Character Card V2
Character Card V3 (CCV3)
World Books and Character Books related features are not supported
#
Starting a Conversation
You can easily start a new conversation using a character:
In the character list, click on any character card
The system will automatically create a new conversation or display existing conversations with that character
Begin interacting with the character
