#
面具功能
面具功能让您可以设定自己在对话中的角色身份，与AI角色进行更加丰富和个性化的互动。
#
面具的作用
在OMate中，面具代表用户自己的角色设定：
用户可以通过面具定义自己的角色特性
面具与AI角色相互配合，创造更加沉浸式的对话体验
系统会在聊天中应用面具设定，形成特定的对话情境
#
管理面具
#
访问面具列表
进入"设置"页面
点击"面具列表"选项
查看所有已创建的面具
#
创建新面具
在面具列表页，点击右上角的"+"按钮
填写以下信息：
名称
：面具的名称（必填）
头像
：上传面具的头像图片（必填）
描述
：面具的角色设定（必填）
点击"保存"按钮完成创建
#
编辑面具
在面具列表中，左滑面具卡片的选项按钮
修改面具信息
点击"保存"按钮应用更改
#
删除面具
在面具列表中，右滑面具卡片的选项按钮
在确认对话框中输入"delete"
点击"删除"按钮确认操作
警告
删除面具操作不可撤销。删除后将无法恢复面具设定。
#
激活面具
在面具列表中，点击"激活"按钮
系统会取消其他面具的激活状态，并激活所选面具
一次只能激活一个面具，或者不激活任何面具
#
在对话中应用面具
#
创建对话时选择面具
创建新对话时，您可以选择一个已有的面具
系统会将面具设定应用到对话中
AI角色会根据您的面具设定调整互动方式
#
修改对话中的面具
在对话界面，点击设置按钮
进入对话管理页面
选择或更换面具
保存设置应用更改
#
面具设定提示
#
编写有效的面具描述
清晰描述您想扮演的角色特征
包含角色的背景、性格和说话风格
添加与AI角色互动的特定方式
避免过于复杂或相互矛盾的设定
#
面具与角色配对
尝试选择与AI角色互补的面具设定
创建特定情境的面具，如"学生"配合"老师"角色
面具描述会作为系统提示的一部分，指导AI如何与您互动
