#
角色管理
角色是OMate的核心功能之一，您可以创建具有独特个性和背景的AI角色，与它们进行深入的对话交流。
#
角色列表
角色列表页面展示了您创建的所有角色。每个角色卡片包含以下信息：
角色头像
角色名称
角色简介
#
创建新角色
创建一个新角色有多种方式：
导航至"角色"页面
点击右上角的"+"按钮，选择以下方式之一：
新建角色
：从头创建一个新角色
导入角色
：从文件导入现有角色
导入URL
：通过URL导入角色
提示
当网络慢时，通过URL或者从发现页面导入时，操作可能持续较长时间，请耐心等待。
#
基本信息
名称
：角色的名字
头像
：上传或选择一个图片作为角色头像（可选）
简介
：一句话描述角色
#
角色设定
第一条消息
：角色的初始问候语
替代问候语
：当第一条消息为空时，会显示多条的问候语供用户选择（每行一条）
性格特点
：角色的个性、习惯和行为模式
场景设定
：角色所处的环境和情境
对话示例
：角色的对话样本，展示语言风格
系统提示词
：指导AI如何扮演该角色的系统指令
历史记录后说明
：在历史记录后添加的额外说明
提示
详细的角色设定可以让AI更好地理解和扮演这个角色，提供更加一致和沉浸式的对话体验。
#
编辑角色
您可以随时编辑已创建的角色：
在角色列表中，左滑角色卡片
点击"编辑"按钮
在弹出的对话框中修改需要更新的信息
点击"保存"按钮应用更改
#
删除角色
如果您不再需要某个角色，可以将其删除：
在角色列表中，右滑角色卡片
点击"删除"按钮
在弹出的确认对话框中输入"delete"
点击"删除"按钮确认操作
警告
删除角色操作不可撤销。删除角色后，与该角色相关的所有对话记录仍会保留，但无法再与该角色进行新的对话。
#
角色导入功能
OMate支持多种角色导入方式：
#
导入本地文件
在角色页面，点击"+"按钮选择"导入角色"
选择本地JSON或PNG格式的角色卡片文件
确认角色信息并保存
#
通过URL导入
在角色页面，点击"+"按钮选择"导入URL"
输入包含角色数据的URL地址
确认角色信息并保存
#
兼容多种角色格式
OMate支持多种角色卡片格式：
Character Card V1
Character Card V2
Character Card V3 (CCV3)
不支持世界书和角色书相关功能
#
开始对话
您可以轻松地使用角色开始一个新的对话：
在角色列表中，点击任意角色卡片
系统会自动创建一个新对话，或展示与该角色的现有对话
开始与角色互动
