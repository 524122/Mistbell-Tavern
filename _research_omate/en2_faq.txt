#
Frequently Asked Questions
This page collects the most common questions and solutions that users encounter. If you encounter difficulties while using OMate, please check the following content first.
#
API-Related Issues
#
Application Cannot Connect to API
Problem
: After configuring the API, the application cannot connect or displays errors.
Solution
:
Check if your API key is entered correctly, with no extra spaces
Confirm that the API base URL is correct
Check if your network connection is normal
Verify that the selected model is available for your account
If using a proxy, ensure the proxy settings are correct
#
API Request Failed
Problem
: "API request failed" error appears when sending messages.
Solution
:
Check if your API account has sufficient balance
Confirm that your API account has not reached usage limits
Try reducing message length, as it may exceed token limits
Check if the network connection is stable
Try using a different API configuration
