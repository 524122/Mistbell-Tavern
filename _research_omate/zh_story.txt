#
故事
OMate的故事模式提供了一种沉浸式的叙事体验，让您可以阅读和体验AI创作的互动故事。
#
故事列表
故事列表页面展示了您的所有故事，每个故事卡片包含以下信息：
故事标题
作者信息
故事简介
参与角色头像
#
添加故事
点击故事列表右上角的&quot;+&quot;号按钮，您可以通过以下方式添加故事：
#
导入故事
文件导入
：上传JSON格式的故事文件
扫码导入
：扫描二维码导入在线故事
发现页面的部分角色也附带了故事书，可以在角色卡详情页面导入
提示
当网络慢时，导入操作可能持续较长时间，请耐心等待。
提示
导入的故事将保存在本地，您可以随时阅读和管理。
#
本地创建故事（测试版）
您还可以在本地创建全新的故事：
在添加故事菜单中选择&quot;创作·测试版&quot;
填写故事基本信息：
故事标题
作者信息（可选）
故事简介
系统提示词（用于指导AI生成故事内容）
选择参与故事的角色（至少选择一个角色）
点击&quot;创建故事&quot;完成创建
提示
创建故事时，第一个选择的角色将被设定为主角。
#
阅读故事
#
开始阅读
在故事列表中点击任一故事
进入故事详情页面
点击&quot;继续阅读&quot;开始体验
#
阅读界面
故事阅读界面包含以下元素：
故事标题
对话内容展示区
继续阅读按钮
故事信息按钮
#
阅读进度
系统会自动保存您的阅读进度
您可以随时退出，下次继续从上次阅读的位置开始
故事读完后，可以选择重新开始阅读
#
AI生成功能
故事模式集成了强大的AI生成功能，让您可以：
#
续写故事
当您阅读到故事结尾时，可以使用AI续写功能：
点击&quot;继续&quot;按钮自动续写
AI会根据当前故事内容自动生成6句后续对话
生成的对话将自动添加到故事末尾
注意
续写时，默认会将角色设置中的&quot;角色设定&quot;和&quot;性格特点&quot;字段放入上下文，可以在故事设置→角色管理中编辑相关字段，此处编辑的内容只对故事生效，不会覆盖角色设置
#
自定义续写
长按&quot;继续&quot;按钮进入&quot;自定义续写&quot;
设置生成参数：
生成句数
：1-20句
续写建议
：输入您希望故事朝什么方向发展的建议
参与角色
：指定哪些角色参与本次生成的对话
点击&quot;开始生成&quot;
#
重写对话
对于已存在的对话，您可以使用重写功能：
#
重写本句
长按任意对话气泡
在弹出菜单中选择&quot;重写本句&quot;
可选择性地输入重写要求（如&quot;更加幽默&quot;、&quot;更有感情&quot;等）
AI会重新生成这句对话
#
重写后续
长按任意对话气泡
选择&quot;重写后续&quot;
设置要重写的句数和重写建议
AI会从当前位置开始重新生成指定数量的对话
#
编辑和删除对话
除了AI生成功能，您还可以手动编辑故事：
编辑对话
：长按对话气泡，选择&quot;编辑&quot;可直接修改对话文字
删除对话
：长按对话气泡，选择&quot;删除&quot;可移除不需要的对话
#
故事信息
每个故事都有详细的信息页面，您可以查看和编辑：
故事名称
作者信息
故事简介
参与角色列表
AI生成配置（API配置、上下文对话数量等）
在故事信息页面，您还可以：
修改故事的系统提示词
配置AI生成时使用的API
调整生成时的上下文对话数量
导出故事配置
#
故事管理
#
删除故事
如果您想删除某个故事：
在故事列表中，向右滑动故事卡片
点击红色&quot;删除&quot;按钮
输入&quot;delete&quot;确认删除操作
#
查看故事信息
在故事列表中，向左滑动故事卡片
会自动进入故事信息页面
警告
删除操作不可撤销，请谨慎操作。
#
使用技巧
#
AI生成优化
合理设置系统提示词
：详细的系统提示词能帮助AI更好地理解故事风格和方向
使用续写建议
：在续写时提供具体的方向建议，如&quot;增加冲突&quot;、&quot;温馨对话&quot;等
选择参与角色
：通过限制参与角色可以让剧情更加聚焦
调整上下文数量
：在故事信息页面可以调整AI生成时使用的上下文对话数量
#
创作建议
角色设定要详细
：在创建故事前，确保参与的角色都有完整的性格设定
分段创作
：不要一次性生成太多对话，可以分批续写并根据效果调整
结合手动编辑
：AI生成后可以手动微调，让故事更加完美
保存备份
：重要的故事可以通过分享功能导出备份
提示
AI生成的内容基于当前的故事上下文和角色设定，合理的设定能获得更好的生成效果。
注意
使用AI功能需要配置相应的API密钥，请在设置中完成API配置。
