# 世界书

世界书是一组按关键词触发的背景设定条目。当对话中出现某个关键词时，对应的设定会被自动注入到 AI 的上下文里——不占用固定篇幅，只在需要时出现。适合存放世界观、地点、组织、事件等"提到才需要"的知识。

与「知识书」的区别：世界书靠关键词精确触发，知识书靠语义向量检索。人名地名等确定性设定用世界书，大段资料用知识书。

# 入口

  • 管理：设置 → 高级设置 → 世界书
  • 绑定角色：角色编辑页 → 世界书区块（勾选后随角色生效）
  • 对话内临时启停：对话管理 → Prompt 标签 → 世界书区块

# 获取世界书

三种方式：

  1. 导入文件：世界书页右上角「导入」按钮，选择世界书 JSON 文件（支持多选批量；SillyTavern 的独立世界书与角色卡内嵌世界书两种格式都能识别）。也可以直接在「角色」页 + → 导入里混着角色卡一起丢进来，会自动识别。
  2. 随角色卡导入：导入带内嵌世界书的角色卡时，会询问是否「导入为世界书」并自动绑定该角色。
  3. 手动新建：世界书页右上角「+」，输入名字后进入详情页逐条添加。

# 编辑条目

进入某本世界书后，点击条目编辑，右滑删除，右上角「+」新建条目。每个条目可设置：

字段 说明
关键词 逗号分隔，命中任意一个即触发（受触发逻辑影响）
次要关键词 配合触发逻辑做「与/非」组合
触发逻辑 andAny（默认）/ notAll / notAny / andAll
位置 角色设定前 / 角色设定后 / 按深度插入聊天记录
深度 位置为「按深度」时，从最新消息往回数的插入位置
顺序 同位置多条目的排序权重（大的在前）
概率 % 触发后按概率决定是否真正注入
常驻 打开后无视关键词，每次都注入
绑定不追溯旧对话

对话保存的是角色快照。给角色新绑定世界书后，已有对话不会自动获得，需要新建对话。

  • 扫描窗口：只扫「参与本次请求的历史消息 + 你正要发送的这条」。太久之前提过的关键词不会触发。
  • 递归：某条目被激活后，它的内容里如果包含其他条目的关键词，会引发第二轮激活（可有多轮，直到没有新增）。个别条目可设「不参与递归/不触发递归」。
  • 时效：条目支持 sticky（触发后持续 N 条消息）、cooldown（触发后冷却 N 条）、delay（对话不满 N 条消息前不触发）。
  • 预算：所有激活条目的总字数受预算限制，超出时按顺序权重丢弃低优先级条目（思考日志里会显示丢弃数量）。
  • 预设也能挂世界书：预设的「世界书挂载」键与角色绑定的书取并集。
